# v0.26.1 Windows FNS 修复发布

## 范围与准备

用户于 2026-10-31 明确要求提交、推送及发布新版本。本次为工作台单独发布，Tag 为 `v0.26.1`；修复提交为 `d939ec8e40253f7e7258efe06e7f042a0de56c6b`，上一正式版本为 `v0.26.0`（`4e26ba17a3315f33ee28d94a58d17a5bf4fcc5f3`）。两者间其余已提交变化为上次发布证据整理。

后台身份查询隐藏 Windows 控制台、复用成功结果并合并在途读取；失败允许重试，设备 ID 算法保持兼容。FNS 页面只响应相关配置输入，合并并串行刷新，离开页面后取消后续工作。具体实现及原生运行证据见[实施记录](implementation.md)。

五个独立 Skill 均继承 v0.26.0 的 1.0.0 正式包，不重新打包开发源、不增加 Skill 清单序号。本次仅交付 `tt-workbench.zip`、`release.json`、`tt-workbench.bundle.json.gz` 三个工作台附件。其他会话未提交的规则 UI、样式、测试及文档保持原位，不纳入本次提交或构建。

发布从已审阅的固定提交 ZIP 导出到 `tmp/release/v0.26.1/source/`，核对全部路径和字节；产物及测试日志保留在同级 `artifacts/`，完成后清理导出源码与验收库。历史审查覆盖拟发布引用全部可达对象、已删除内容、已知秘密模式、大文件、LFS 和子模块，不承诺识别全部秘密。
