## Decisions-so-far

- 新工作台仓库位置为 `D:\zhao\tt-workbench`，这是用户已明确的目标。
- GitHub 远端由后续步骤设置，本轮不推定仓库地址或发布权限。
- **Q1 已确认**：继续采用 Obsidian 插件形态，将源码仓库、安装包与目标知识库分开。
- **Q2 已确认**：本轮迁仓同时做通独立打包、测试和指定知识库安装。用户在明确“安装脚本将插件文件安装到目标 Obsidian 库”的含义后，对 Q1、Q2 均答复按推荐。
- **Q3 已确认**：允许任意名称、任意位置的 Obsidian 库，首版沿用现有五目录和项目／任务格式。术语表中的“工作台”相应改为面向所使用的知识库，不将固定库名当作领域边界。
- **Q4 已确认**：工作台与 Agent 共用的文件读写、FNS 等程序一起迁入新仓统一维护，tannt 使用安装后的工具；现有 Skill 在 Obsidian 关闭时仍然可用。
- **Q5 已确认**：新仓从当前代码开始新的 Git 历史，历史修改继续在 tannt 仓库回查。
- **新增明确要求**：当前项目的 Skill 源码也放入工作台仓库。工作台 UI 将提供仓库内 Skill 的安装功能；该新功能的需求梳理、UI 原型与用户确认在代码迁至新目录之后开展，见[后续需求](../workbench-skill-installation/spec.md)。
- **执行顺序**：先完成源码迁移与独立安装验收，包含 Skill 源码及维持现有工具和发现入口所需的调整；随后在新仓开展 Skill 安装 UI 的设计访谈和原型确认。登记后续需求不表示已经设计、获准界面方案或完成实现。
- 上述架构决定记入 [ADR 0005](../../docs/adr/0005-independent-workbench-repository.md)。这不代表下列待定边界已获确认，也不代表迁移或验收已完成。
- 按所调用的 grilling 流程逐轮确认设计；术语明确后即时更新术语表，有实际架构取舍时记录 ADR，形成共同理解后实施迁移。

## Fog

### 第三轮：已提出，待回答

Q1—Q5 已确认。新增 Skill 源码迁移要求覆盖此前“Skill 可能留在 tannt”的调查建议。已复核五个 Skill 及其安装器：源码根与目标库根必须分开；当前 Codex、Claude 各五个项目发现链接均指向原库 Skill 源码，迁仓必须核验后迁接已知旧入口。网盘授权路径检查及全局指令安装器也必须按真实目标库定位。该调查只服务迁仓，不提前展开安装 UI 的设计。

**Q6：源码与知识库材料边界。** 推荐迁出程序、Skill、测试、使用说明和专属开发资料；业务笔记、知识库规则、业务模板、个人配置及既有运行／恢复记录保留原位。混合了实际知识库或设备情况的历史材料留在 tannt，通过引用回查；本轮保留现有运行记录目录。

**Q7：新库安装行为。** 推荐安装只放入插件与配套工具，业务目录在实际使用中按既有规则按需创建；保留现有笔记和设置。FNS、网盘、Agent 规则等未配置时明确提示，基础工作台仍可使用；Skill 安装 UI 流程在迁仓后讨论。

**Q8：更新来源。** 推荐软件更新改为独立工作台来源。GitHub 远端未配置期间使用本地安装脚本更新，界面显示更新源未配置；知识库自己的 Git 远端继续服务知识库及 FNS 配置。

具体迁移范围、保留范围、切换与验收步骤汇总于[实施方案](spec.md)，其中 Q6—Q8 仍为待确认推荐，不能记作已批准。

### 决策树与实施方案的对应关系

只读事实调查已完成，具体源码范围、八个历史脚本例外、技术文档清单与验收步骤已纳入实施方案。当前需用户决定的迁仓分支为 Q6—Q8；其余为按已确认约束执行的实现与核验事项。

1. **产品与安装范围**：Q1—Q3 已确认，Q7 决定空库及缺少可选集成配置时的行为；明确选择目标库、保留现有身份与文件由安装实现负责。
2. **唯一源码与使用方**：Q4 及五个 Skill 源码归属已确认，Q6 决定技术文档和知识库材料的边界；工具接续与十个现有发现链接列入实施验收。
3. **运行记录与存量迁移**：Q6 决定保留现有位置，全部读写方、Git 忽略与适用 FNS 排除在切换时一致核验。
4. **发布与更新**：Q8 决定独立来源和无远端期间的行为；GitHub 地址由用户后续提供，知识库 FNS 配置传输保持独立。
5. **迁仓历史与验收**：Q5 已确认；完整方案规定按实际源版本准备恢复材料、先验证目标和引用再移除源代码，以及分别报告各平台和入口的证据。
6. **Skill 安装 UI**：按用户明确顺序留在迁仓之后开展需求与原型确认，不作为当前迁仓尚未解决的前置问题。
