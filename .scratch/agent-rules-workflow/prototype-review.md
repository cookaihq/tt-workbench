# Agent 规则只读页面原型评审

## 已明确的页面职责

用户在首轮原型后纠正了职责边界：整理建议、分析、歧义澄清和方案确认属于 Skill，在 Agent 会话中返回和讨论。随后进一步明确页面不编辑文件、不查看文件差异；本机全局规则没有通过当前项目的符号链接接入时，页面显示状态及调用 Skill 的提示词。

当前页面仅提供：

1. 只读浏览全局主规则和场景文件，标明本机原文件与当前项目正式源。
2. 显示本机规则入口是否通过符号链接接到当前项目，以及实际位置和目标。
3. 未接入或发现入口问题时，直接显示可复制的 Skill 调用提示词；已正常接入时隐藏该提示。
4. 用户完成 Agent 操作后刷新，重新读取文件与链接事实。

页面没有编辑、差异、整理建议、问答、逐条采纳或确认流程，不依赖 Skill 返回整理记录。

## 打开方式

可以直接在浏览器中打开原型文件，也可以在库根目录运行：

```powershell
python -m http.server 8946 --bind 127.0.0.1 --directory docs/prototypes/workbench
```

打开 `http://127.0.0.1:8946/agent-rules-prototype.html?variant=A&scenario=local`。切换成 `scenario=connected` 可查看已正确接入时的页面。
