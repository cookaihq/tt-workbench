# FNS 应用提示中的快捷配置

2026-10-29，用户提出在“此版本不能直接应用到本机”的提示处添加小按钮，点击即可配置。

复用现有本机补齐入口，在提示条直接执行「补齐本机排除」，使用原有暂停、恢复材料、原文核对、写入和加载核验。执行期间停用操作，完成后重新读取本机状态；失败展示原因并允许重试。

提示针对收到的权威版本，本机补齐不改变该版本。已齐全时显示「比较并发布」，进入现有发布预览与确认；仍阻止直接应用不符合要求的旧版本。保存但未加载、待推送记录、检查失败和远端发布异常分别按实际状态显示。

保留「本机检查」作为完整检查与故障处理入口。只新增界面快捷操作，不改变 FNS 四组规则的含义、CLI、传输协议、安装行为或其他设备配置。真实知识库安装须有明确目标路径。

验收：按钮直接执行、防重复点击、错误重试、配置后发布预览、禁止自动发布或应用、待加载与待推送状态、检查失败与异常版本；完整测试、构建、宽窄窗口和隔离安装。证据见 implementation.md。
