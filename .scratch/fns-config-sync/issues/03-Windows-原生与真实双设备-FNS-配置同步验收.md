# Windows 原生与真实双设备 FNS 配置同步验收

正式实现与当前 macOS 验证见 spec.md 及 verification/implementation.md。以下需要对应设备和受控文件到场后执行，不以夹具或原型代替。

- [ ] Windows 原生身份、普通配置直接使用、旧链接迁回及重复执行（0.21.0 起取消建链权限要求）。
- [ ] 两台设备通过已有远端发布、接收、比较并明确应用；确认各自账号和其他设置保留。
- [ ] 使用受控文件验证额外纳入、排除目录、排除扩展名和白名单的实际传输效果。
- [ ] Windows 实际 FNS 暂停、恢复、再次保存与失败恢复。
