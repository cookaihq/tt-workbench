# 网盘托管文件与项目级管理 Skill

## 已确认需求

- MP3、MP4、MOV、WAV、ZIP 原文件不经 FNS 传输，由百度网盘托管。
- 同目录 `<原文件完整名称>.yaml` 为托管替代文件；本机原文件缺失时下载到它所在目录，恢复原名。
- 网盘映射为 `<指定目录>/tannt/<库内相对路径>`。
- 非敏感目标唯一保存在`config/cloud-storage-targets.jsonc` 并通过 FNS 普通文件同步，默认账号加按次指定、各账号分别配置父目录。本机支持多个独立授权账号，替代文件记录授权别名与可核对的百度账号 ID。
- 本地移动、改名时同步调整网盘路径、替代文件及引用；用户最终明确采用该推荐。此前平铺与远端固定路径方案均未采用。
- 创建本库使用的 `tannt-cloud-files` Skill，维护托管文件。
