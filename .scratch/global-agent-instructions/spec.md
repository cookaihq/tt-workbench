# 全局 Agent 指令正式维护位置

用户确认 tannt 作为跨项目使用的全局主指令及全局场景指令的正式维护位置；各项目自己的场景指令继续在各项目维护。

## 实施范围

- 建立 `docs/global-agent-instructions/AGENTS.md` 与全局场景目录，保留原主文件第一行来源说明之后的全部正文。
- 增加全局指令维护场景和主文件读取入口，明确全局与项目范围。
- 将 Codex、Claude Code 的用户级加载入口接到库内同一源，提供可重复执行的安装与检查命令。
- 更新 tannt 的维护入口、目录说明和设计决定；保留迁移前版本及验收证据。

## 非目标

不重写原规则，不将各项目指令集中到此处，不迁移 Skill、凭证、执行权限配置；不修改其他项目、FNS 或初始化 Git。不把当前设备验证扩展为双电脑、Windows、Cowork 或云端支持声明。

## 验收标准

- 原主文件既有正文完整保留，有哈希和历史快照可回查。
- 用户级链接全部解析到库内正式源；重复安装不会覆盖已有内容。
- 全局主文件包含全局场景的明确触发条件和读取入口，场景能从其他工作目录解析。
- Codex 从库外工作目录加载完整全局主文件，不带入 tannt 项目指令。
- Claude Code 的实际加载结果独立核验；未验证不得记为通过。
- tannt 的项目指令与全局指令分开，其他项目文件未修改。

实施状态及实际版本见[验收记录](verification/README.md)，迁移基准见 [baseline.json](verification/baseline.json)。
