# FNS 按设备保存完整配置

Status: ready-for-human

> 2026-10-28：本方案的运行配置外移、符号链接及自动建链流程已被用户确认取消。当前实现与验收以 [FNS 同步规格的本轮变更](../fns-config-sync/spec.md#2026-10-28取消运行配置外移与符号链接) 为准；下文保留历史决定及验收范围。

## 用户确认

2026-10-25，允许多份完整 `data.json`（含各设备 Token）进入 Git。Skill 每次执行检查插件配置是否为符号链接：普通文件移到对应设备目录并建链；缺少文件则提示安装 FNS。此前仅拆分四个共享字段的建议未采用。

后续指定目录为 `config/fns-config/`，不使用点号前缀。已知旧位置的本机配置与链接随迁移更新；普通目录通过精确排除规则保持仅由 Git 传递。

## 实施范围

- 正式流程：`docs/agents/fns-device-config.md`；设备配置目录 `config/fns-config/<设备标识>/data.json`。
- `tannt-sync-agent-config`、清单、项目入口明确自动迁移授权；其余配置值调整仍按原流程。
- `scripts/fns/device-config.mjs` 负责稳定设备标识、只读检查、迁移及旧链接修复、Git 忽略本机入口及恢复记录。除补齐 `^config/fns-config(?:/|$)` 排除项外，保留 Token 和其他设置值。
- FNS 单文件同步维护工具写入真实目标，保留符号链接。
- 不初始化或切换仓库，不自动提交或推送，不复制其他设备 Token，不统一多份配置中的四组规则。

## 验收

- 已通过：迁移、重复执行、缺配置、断链、不同目标冲突、多个设备身份和 Token 隔离、旧目录迁移、Git 已移动文件后的旧链接修复、精确排除与白名单冲突检查。设备配置、FNS 维护及隐藏项检查测试合计 46 项通过。
- 已通过：当前 macOS 实际迁入 `config/fns-config/`，FNS 在设置界面停用及重新启用；本机配置归属正确、Token 保留，旧目录清理，重复执行无变更。详见[本机验收及迁移续验](verification.md)。
- 已通过：FNS 重载后设置界面显示新增排除规则；在界面用同一规则值触发保存后，链接仍指向本机新位置，Token 和其他设置值不变。
- 待现场验证：Windows 原生文件符号链接、权限不足及真实插件保存；Git 在另一设备拉取后按该设备身份选择配置。

恢复与临时验证材料保存在已排除同步的 `apps/workbench/data/`；正式验收摘要追加在本记录，不写入 Token。
