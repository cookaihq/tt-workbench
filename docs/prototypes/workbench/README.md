## Inbox 提案与原型的关系

完整的录入入口、目录、属性、工作台读取与写回流程，以及后续决策见 [Inbox 讨论稿](inbox-proposal.md)。本稿替代此前的收藏保存提案。第一阶段已确定优先规划工作台输入、Obsidian 直接记录、各 Agent 共用的保存 Skill 和浏览器剪藏；原型仍只演示工作台内的内存交互。

当前原型演示以下操作：

1. 可以只填一句话或粘贴一个链接，标题选填，不要求分类或解释保存理由。
2. 保存后进入待整理列表，不自动创建项目或任务。
3. 当时的输入与后续补充分开显示。
4. 可以关联一个已有项目；这不等于开始执行任务，也不改变整理状态。
5. 标为已整理后，从默认待整理列表隐藏；原记录在“已整理”和“全部记录”中继续可见，并可重新放回待整理。
6. 列表按浏览器所在设备的时区显示创建时间及偏移，页面标明显示时区；详情保留原始时间及偏移。示例同时包含 `+08:00` 和 `-07:00` 的记录，按实际时刻倒序；随手记使用当前设备的同一时刻生成时间与偏移。
7. 明确决定推进时，可以创建独立任务或项目内任务，填写预期结果；也可以关联一个已有任务。原记录、创建时间和整理状态保留，任务详情提供返回来源的入口。

“整理后原位保留”及四项优先录入入口已经确定。已明确归属的内容也可直接保存到对应课程、项目或任务；原型的“随手记”目前只演示进入 Inbox 的操作。手动录入是在 `收件箱/` 下新建 Markdown 并应用模板；程序／Skill 可以按月创建条目文件夹。两者在工作台中均作为记录展示，不自动迁移手动笔记。AI 完成摘要或解析不自动标为已整理，须由本人或明确获授权的 Agent 标记。最小模板包含类型、整理状态、创建时间和所用时区；普通附件默认读取 Obsidian 设置，用户在 Agent 中明确指定的位置优先。时间展示已确认并在示例中演示；第 02 项已实现工作台的原文及可选来源链接保存；正式关联使用 Inbox 的 related_work 笔记链接，并由工作台反向读取；本机 Codex 和 Chrome 文字剪藏已经接入。文件导入、语音转写及自动采集尚未实现。

“觉得有启发”“可能成为选题”“某个元素做得好”可以作为自己的自由记录，不再设置为三个固定入口。

## 可操作的演示

- 进入“项目”，选择企业A的培训项目，查看目标、项目说明和任务，分别修改 Project 与 Task 状态；把全部任务标为已完成，项目状态仍由自己决定。
- 新建企业交付项目、通用培训内容开发项目、某创作方向下的项目或社群项目，检查显示的说明笔记路径。
- 从项目“添加任务”或任务页“新建任务”创建项目内任务，也可以选择独立任务。
- 打开项目任务、修改状态和进度，通过“查看所属项目”返回。
- 从任务或项目直接阅读相关笔记。
- 在任务“查询 Agent”页复制查询 Prompt。
- 点击“随手记”，只填写内容后保存到演示收件箱。
- 给收件箱记录补充文字、关联已有项目，明确创建或关联任务，再从任务返回原记录；标为已整理后仍能找回。
- 进入“浏览笔记”，从资料、知识或领域目录选择笔记；搜索正文，再查看候选选题、账号笔记和可复用培训大纲。
- 修改任务进度后，在“浏览笔记”打开对应任务说明，看到同一份演示数据中的最新状态和进度。
- 在各页面搜索；任务仍支持领域、企业、项目和五种状态筛选。

所有人物、企业、任务、来源片段和进度均为界面示例，不代表已执行的真实工作或真实来源的说法。页面操作只修改浏览器内存，刷新即恢复；不使用浏览器持久存储，不读写实际笔记，不连接 FNS，不查询或启动 Agent，也不访问私人库。

Q52 已确认 Project 状态在 `项目说明.md` 的 YAML 属性中保存，Task 状态、进度和下一步在 `任务说明.md` 的 YAML 属性中保存；本人和获授权的 Agent 明确更新状态。原型内存对象只用于交互演示，不能据此理解为正式实现采用独立 JSON。业务状态不能证明 Agent 正在运行，创建工作记录也不会启动 Agent。

## 与正式实现的边界

原型不读写真实文件，刷新后示例复原。正式插件使用真实 Markdown，实现项目与任务、Inbox、来源关联、目录与正文搜索，以及本机 Codex 保存、Chrome 剪藏、普通模板复用和附件保存。业务状态仍在说明笔记的 YAML 中，未引入可编辑 JSON 状态副本。正式能力、环境与限制见[使用说明](../../../apps/workbench/README.md)和[实际验收索引](../../../local-evidence/docs/workbench/verification/README.md)。

2026-10-16 根据用户指出的界面差异，修正正式实现的导航、页面结构、列表与详情、配色、弹窗及任务详情标签；原型继续作为参照。原型示例企业、任务与知识分类不复制成默认业务内容。实际验证文件均明确标注“工作台验收”，来源网页剪藏另保留真实标题。

FNS 网页尚未取得笔记正文；正式阅读使用 Obsidian 文件接口。工作台不启动或监控 Agent；查询 Prompt 的界面与系统剪贴板已验证，新会话查询仍待验收。双电脑 FNS 未完成，不能用本机截图或保存结果代替。课程文件、课时输出及 AI 整理流程继续按需确定。
