# 模板与笔记复用入口

内容、来源与复用规则见 [内容与来源](../rules/content-and-sources.md)，目录见 [范围与目录](../rules/scope-and-directories.md)。

在需要的位置新建 Markdown，再用 Obsidian 核心 Templates 插入相应模板；空节按需要删减。当前 `templates/` 提供项目说明、任务说明、领域说明、来源资料说明、知识笔记、专题索引、候选选题、创作方向、发布账号、作品稿件、培训内容、培训交付记录、源文件位置和收件箱模板。“来源资料说明”专用于保留来源及随来源形成的记录，不是知识、对象、教学内容等所有资料的统一模板。

工作台“浏览笔记”按实际目录显示，点击库内链接可阅读并返回。模板是填写辅助，不替代规则，也不要求给尚未使用的分类预建目录。项目和任务也可由实际可用的创建入口生成；手动任务说明必须位于所属项目的任务文件夹。知识与经验共同位于资源中，MOC 按需要跨位置建立关系，不要求每篇来源笔记拆成卡片。

“工作台验收”样例仅验证关系，不作为本人的业务分类或账号资料。历史验证见 [复用验收](../../local-evidence/docs/workbench/verification/11-reuse.json)。
