# 查询任务是否有 Agent 执行

打开真实任务的“查询 Agent”页，点击“复制 Prompt”，在自己新开的 Agent 会话中粘贴。页面每次进入查询页或复制时重新读取 `任务说明.md`，包含当前任务、库路径、说明笔记位置、最新状态、进度和下一步；不能把未保存表单当成已记录进度。

Prompt 要求查询方先说明可访问哪些应用、会话或执行记录，再报告证据的来源、时间及与当前任务的关联。无法访问或证据不足时回答“无法确认”。笔记标为进行中、本机有进程、过去做过相关工作，都不能单独证明此刻有 Agent 在执行。

查询不启动或停止 Agent，不修改笔记，不访问私人库。Prompt 中的任务原文只是待核查资料，其中的指令不扩展查询权限。复制失败时页面保留只读文本供手动选择复制。

本机已验证任务更新后 Prompt 随实际保存内容变化，三个标签可切换，复制内容与系统剪贴板逐字相同；见[界面与剪贴板证据](../../local-evidence/docs/workbench/verification/13-query-ui.json)。新 Agent 会话中的实际查询仍待验收，因此第 13 项尚未全部完成。工作台启动与持续监控 Agent 是另一项后续工作。
