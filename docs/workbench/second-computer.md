# 在另一台电脑接入

从工作台软件仓库或完整发布包取得软件，按根 [README](../../README.md) 安装到该设备实际知识库，参数必须使用本机路径。保持知识库笔记、账号和设备配置的既有传输方式；软件安装不承担知识库迁移。

启用插件后，检查运行版本和笔记读取。需要 Skill 时独立[注册项目发现入口](agent-skill-setup.md)，新会话检查实际发现并验证一次所需操作。需要全局规则时使用独立整理流程，先核对原规则和正式源，不照搬另一设备的用户目录或入口。

FNS、飞书、网盘都是可选配置。按目标知识库 `config/agent-config-checklist.md` 检查期望；FNS 配置快照使用知识库自己的 Git 远端，保留本机身份与 Token。双机同步需用获准的样例验证实际到达、冲突与恢复，不能以本机配置相同推断另一台已同步。

软件更新源在版本页面配置公开 GitHub 仓库。尚无远端时使用本地安装器；新版本只提示，用户点击后安装并重启。实际支持与未验证范围见迁仓验收记录，Windows 的通过不自动代表 macOS 或 WSL。
