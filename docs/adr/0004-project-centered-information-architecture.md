# 采用五目录组织工作与资源，以卡片和索引连接认识

## 已接受的决定

用户最新指定业务根目录为 `0.收件箱/`、`1.项目/`、`2.领域/`、`3.资源/`、`4.存档/`，取代此前的目录候选及中间轮次取消领域的选择。导航采用库根首页和按需 MOC，不设独立导航、待考虑或独立任务根目录。采用 PARA 组织宏观结构，卡片盒用于知识表达和连接；链接可以跨目录。

用户已接受 Q22 的适配 PARA：项目以已决定推进且范围明确界定，允许有限交付、长期研究和运营；领域承载持续责任、标准与运行记录；资源保存供理解和复用的知识与材料。每个任务属于项目，行动在任务内维护；领域不是项目创建的必填前提，单纯兴趣积累不自动产生工作承诺。

用户已接受 Q23 的明确物理归档：归档是获授权的整包迁移，保留专属材料、原身份和状态，更新引用并提供恢复依据。完成、取消或暂停不自动移动，仍在独立复用的资源保留原位。此决定替代此前“只通过历史视图原位保留”的方案。

输出仍是工作流概念，成果按项目、任务及内容需要组织，不设统一成果总览、成果库或强制登记。用途可选，多项用途分别更新并回查实际使用的内容。知识与经验共同组织，保留本人实践身份与证据；卡片和 MOC 按需形成，不机械拆分所有来源记录。

## 前五轮讨论背景（已被最新决定部分替代）

以下保留决策形成的上下文，其中“领域仅为分类与索引”“资料主区”“待考虑另列”“无物理归档”等以本文件已接受决定及共同规则为准。完整回答历史保存在讨论地图，不将历史描述作为另一份现行规范。

本库以推进工作为第一优先。项目集中组织，领域作为可选的分类与索引，不再以领域、客户或创作方向的多层目录作为项目成立的前提。项目可以承载长期研究或运营；正式工作保持项目与任务两层，简单工作由任务承担，需要独立管理多项任务的交付另建平级关联项目。

经验纳入统一知识体系，保留本人实践身份和依据。课程学习、开发及授课属于工作，课程来源和长期维护的教学内容分别归属可复用的内容。输出无需预先确定用途；同一内容的多项用途分别跟踪，共同关联原内容，并能回查实际使用情况。

第四轮确认：输出仅作为工作流概念，成果按各项目、任务或内容自身需求组织，撤回统一成果总览建议。共用内容集中区分知识、来源、对象和可复用内容；收件箱只承接待决定的输入，明确去向后分流，待考虑的想法另列。已结束工作通过状态与历史视图区分，文件保留原位；采用开工选重点、每周短回顾的使用节奏。

第五轮修正：每个任务必须属于项目，暂未找到业务归属的任务可以放入专门容纳此类工作的项目，取代允许独立任务的旧约定。共用内容主区命名为“资料”，扩大资料定义，原狭义类别称“来源资料”。卡片与 MOC 按需形成，日期和等待信息可选；解除内容项目只能属于一个创作方向的硬限制，不同方向的工作通常分别建立项目。导航的必要性、领域的独立职责及最终目录仍在重新检验。

## 取舍

原方案将项目嵌入领域、客户和创作方向，便于按既定分类浏览，但创建和寻找工作需要先选择分类层级。选择集中项目并通过索引、关联表达其他视角，可以容纳跨分类工作和长期项目，同时需要重新设计归属识别与相关入口。与严格以可结束目标区分 PARA 项目的做法不同，本库以明确范围和已决定投入来界定项目，由可完成的任务承载具体推进。

知识与经验分别建立平行集合，能突出实践积累，却容易分散同一问题的认识。统一组织后，实践身份、适用条件和证据仍需明确，不能把外部材料或 AI 推断写成本人已经验证的结论。具体业务规则在共同规则中维护，本 ADR 记录组织选择及其原因。
