# 将 Agent 指令维护作为可独立使用的通用 Skill

`agent-instructions` 面向任意用户，覆盖全局与项目指令的新建、增补、审查、拆分整理和读取入口修复。源码仍由本仓库维护，但安装与运行不要求 Obsidian、工作台或指定知识库；用户个人规则不作为公共 Skill 的必备内容。

现有 `tt-organize-agent-rules` 只处理已有全局规则的整理与接入，并依赖工作台软件资源及明确的目标知识库。继续沿用这一边界无法支持任意项目的日常指令维护，因此选择独立使用的新 Skill，并承担拆除软件包依赖、支持用户既有规则布局和适配安装入口的成本。新 Skill 完成后退役旧 Skill，配套处理已有发现入口、页面调用、活动清单和分发内容。

用户显式选择安装 Skill 时，独立安装入口和工作台入口均默认安装到所选 Agent 的用户级位置。安装工作台本身不自动注册 Skill，也不因此修改用户规则或其加载入口；这延续 [ADR 0005](0005-independent-workbench-repository.md) 对插件安装的边界。

本决定确认产品范围与独立性，不表示实现、安装或退役已经完成。宿主范围、规则组织、分发更新和迁移细节继续在[规划记录](../../.scratch/agent-instructions/spec.md)中收敛。
